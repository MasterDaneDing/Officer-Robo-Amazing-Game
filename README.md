# Officer Robo's Amazing Game!

Children's educational board game about good behaviour in different parts of the city.

## How to play
1. Download the full game files (HTML + board + character images + music + encounter art).
2. Keep them all in the same folder.
3. Open `officer_robo_game.html` in a browser.
4. Choose 1-4 players, pick characters, enter names, and play.

## Features
- 5 robot police officer characters
- Circular board with themed zones (neighbourhood, train, eating street, highway, dangerous street)
- Educational multiple-choice encounters
- Scoring, two laps, victory screen
- Theme music

Made for classroom use.
